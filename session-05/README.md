# Session 05 — Object Detection and Shape Analysis

A 50-minute 1:1 session on using contours and simple geometry to detect, classify, count, and measure controlled shapes.

- **Learning goal:** explain what a contour measures, then use area, perimeter, corners, and a bounding box to make and test a shape rule.
- **Notebook:** `notebooks/05_shape_analysis.ipynb`
- **Scope limit:** this lesson uses controlled shapes; later deep-learning sessions handle varied real-world objects.
