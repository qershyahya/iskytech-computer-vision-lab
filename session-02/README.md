# Session 02 — Image Manipulation for Vision

A complete 50-minute continuation of the Computer Vision Lab.

| Time | Activity |
|---|---|
| 0–6 min | Frame the pixel transformation problem |
| 6–16 min | Predict what each manipulation removes or distorts |
| 16–31 min | Compare the real source and controlled transformations |
| 31–38 min | Run the notebook and change one parameter |
| 38–45 min | Stress the input with a deliberate failure case |
| 45–50 min | Record evidence and complete the responsible-use exit ticket |

The page includes an optional, hideable timing cue. The notebook downloads locally or opens in Colab.
