# Session 04 — Color Filtering and Masks

A 50-minute lesson in which learners build a simple HSV rule, inspect the raw binary mask, clean it with morphology, and measure its largest connected region. The notebook is designed for Google Colab and uses the lesson image rather than a webcam, so every learner starts from the same controlled evidence.

- Slides: `index.html`
- Colab notebook: `notebooks/04_color_filtering_masks.ipynb`
- Original lesson assets: `assets/`
